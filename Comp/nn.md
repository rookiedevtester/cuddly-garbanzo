Translator
: ***definition***
: Assembler
	: A program that translate assembly language into machine codes. It is only used in *low-level programming languages*.
: Compiler
	: A program that translate source program into machine codes, where the *object code* is generated after the process. The compiler displays the list of errors and warnings for the statements violating the syntax rules of the language. Compilers also have the ability of linking subroutines of the program.
: Interpreter
	: A program that generates object code
